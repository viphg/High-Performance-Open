# 前端页面结构与流程 (Pages & Routes)

## 页面导航树

```
High-Performance SPA
├── 认证相关 (无需登录)
│   ├── /auth/login                  # 登录页
│   ├── /auth/register               # 注册页
│   ├── /auth/forgot-password        # 忘记密码页
│   └── /auth/reset-password/:token  # 重置密码页
│
├── 核心页面 (需登录)
│   ├── /dashboard                   # 仪表盘（首页）
│   ├── /goals                       # 目标列表
│   │   ├── /goals/new               # 新建目标
│   │   └── /goals/:id               # 目标详情 & 编辑
│   │
│   ├── /tasks                       # 任务列表
│   │   ├── /tasks/new               # 新建任务
│   │   ├── /tasks/board             # 看板视图
│   │   └── /tasks/:id               # 任务详情 & 编辑
│   │
│   ├── /achievements                # 成就中心
│   │   ├── /achievements/badges     # 徽章展示
│   │   └── /achievements/stats      # 成就统计
│   │
│   ├── /analytics                   # 分析页面
│   │   ├── /analytics/overview      # 概览
│   │   ├── /analytics/goals         # 目标分析
│   │   └── /analytics/tasks         # 任务分析
│   │
│   └── /profile                     # 个人中心
│       ├── /profile/settings        # 账户设置
│       ├── /profile/notifications   # 通知设置
│       ├── /profile/privacy         # 隐私设置
│       ├── /profile/data-export     # 数据导出
│       └── /profile/security        # 安全设置
│
├── 共享页面 (公开或有链接访问)
│   ├── /share/:token                # 公开分享页面
│   └── /public/:username            # 用户公开主页（可选）
│
└── 错误页面
    ├── /404                         # 页面不存在
    ├── /500                         # 服务器错误
    └── /403                         # 无权限访问
```

## 页面详细设计

### 1. 认证相关页面

#### 1.1 登录页 (`/auth/login`)
```
Header: High-Performance Logo
────────────────────────────
内容区域:
├─ 表单卡片
│  ├─ 邮箱/用户名输入框
│  ├─ 密码输入框
│  ├─ [登录] 按钮（全宽）
│  ├─ [忘记密码?] 链接
│  └─ [还没有账户？注册] 链接
│
└─ 社交登录（可选）
   ├─ Google OAuth
   └─ GitHub OAuth

布局: 居中单列，宽度 400px
风格: 简洁、专业、深色/浅色模式支持
验证:
  ✓ 邮箱格式验证
  ✓ 实时密码强度提示
  ✓ 登录失败显示错误信息
  ✓ 加载状态显示
```

#### 1.2 注册页 (`/auth/register`)
```
Header: High-Performance - 加入我们
────────────────────────────
表单流程:
Step 1: 基本信息
├─ 邮箱输入
├─ 验证码获取（发送到邮箱）
├─ 验证码输入（60 秒倒计时）
└─ [下一步] 按钮

Step 2: 账户信息
├─ 用户名输入（实时检查唯一性）
├─ 密码输入（含强度指示器）
├─ 密码确认
├─ [服务条款] 复选框
└─ [注册] 按钮

验收标准:
  ✓ 实时验证邮箱唯一性
  ✓ 密码强度要求提示
  ✓ 多步表单流畅切换
  ✓ 注册后自动登录
  ✓ 跳转到仪表盘
```

#### 1.3 忘记密码页 (`/auth/forgot-password`)
```
表单:
├─ 邮箱输入
├─ [发送重置链接] 按钮
└─ 成功提示
   "我们已将重置链接发送到 user@example.com"
   "请在 24 小时内点击链接重置密码"

验收标准:
  ✓ 邮箱验证
  ✓ 发送成功提示
  ✓ 支持重新发送
```
