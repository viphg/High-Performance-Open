# 功能需求文档 (FRD)

## 1. 用户认证与账户管理

### 1.1 用户注册
```
需求: 用户可以通过邮箱或手机注册账户
流程:
  1. 输入邮箱/手机、密码、验证码
  2. 验证邮箱/手机
  3. 创建账户，自动登录
4. 跳转到新手引导

验收标准:
  ✓ 支持邮箱和手机双注册方式
  ✓ 密码强度验证 (6+ 字符，含大小写数字)
  ✓ 验证码 5 分钟有效
  ✓ 重复邮箱提示已注册
```

### 1.2 用户登录
```
需求: 用户可以安全地登录账户
流程:
  1. 输入邮箱/用户名、密码
  2. 验证凭证
  3. 返回 JWT Token（刷新令牌 7 天）
  4. 保存 Token 到 localStorage

验收标准:
  ✓ 登录失败提示错误次数，5 次后锁定 15 分钟
  ✓ Token 自动刷新，无需重新登录
  ✓ 支持"记住我"功能（30 天）
```

### 1.3 密码管理
```
需求: 用户可以安全地重置和修改密码
功能:
  - 忘记密码: 邮箱验证 → 重置链接
  - 修改密码: 输入旧密码 → 新密码验证
  - 密码历史: 不能使用过去 5 个密码

验收标准:
  ✓ 重置链接 24 小时有效
  ✓ 修改密码后强制重新登录
```

### 1.4 个人档案管理
```
需求: 用户可以管理个人信息
信息字段:
  - 昵称 (2-20 字符)
  - 头像 (JPG/PNG, < 5MB)
  - 自我介绍 (0-500 字)
  - 时区 (影响邮件发送时间)
  - 语言偏好 (中文/英文)

验收标准:
  ✓ 支持头像上传和 CDN 加速
  ✓ 实时保存，无需显式提交
```

## 2. 目标管理

### 2.1 创建目标
```
需求: 用户可以创建带有基本信息的目标
输入字段:
  - 目标标题 (必填, 1-100 字)
  - 目标描述 (可选, 0-1000 字)
  - 分类 (career/health/learning/finance/personal)
  - 目标类型 (长期>365天 / 中期90-365天 / 短期<90天)
  - 目标日期 (deadline)
  - 可见性 (private/shareable)

验收标准:
  ✓ 日期不能早于今天
  ✓ 标题不为空
  ✓ 创建后自动设置为"进行中"状态
```

### 2.2 编辑目标
```
需求: 用户可以修改已创建的目标信息
可修改字段:
  - 标题、描述、分类、日期、可见性
不可修改:
  - 创建时间、目标 ID

验收标准:
  ✓ 编辑后更新修改时间
  ✓ 支持撤销修改（最多 5 步）
```

### 2.3 目标进度追踪
```
需求: 用户可以手动或自动更新目标进度
方式:
  1. 手动输入进度百分比 (0-100%)
  2. 自动计算: 基于关联任务完成率
  3. 里程碑: 用户可添加中间检查点

验收标准:
  ✓ 进度更新有历史记录
  ✓ 提供进度预测（按照当前速率，完成日期预测）
```

### 2.4 目标状态管理
```
状态转移:
  进行中 → 暂停 → 进行中
  进行中 → 已完成
  进行中 → 已放弃

验收标准:
  ✓ 状态变更时触发邮件通知
  ✓ 已完成目标自动记录成就
```

### 2.5 查看目标列表
```
需求: 用户可以查看自己的所有目标，支持过滤和排序
过滤选项:
  - 状态: 进行中 / 已完成 / 已放弃 / 暂停
  - 分类: career / health / learning / finance / personal
  - 时间范围: 本周 / 本月 / 本年 / 全部
  
排序选项:
  - 创建时间（最新）
  - 截止时间（最近）
  - 进度（最低 → 最高）

验收标准:
  ✓ 支持搜索目标标题
  ✓ 列表分页（每页 20 条）
```

## 3. 任务管理

### 3.1 创建任务
```
需求: 用户可以创建任务，可关联到目标
输入字段:
  - 任务标题 (必填)
  - 任务描述 (可选)
  - 关联目标 (可选)
  - 优先级 (高/中/低)
  - 截止日期 (可选)
  - 预估耗时 (小时，可选)
  - 任务标签 (可选，逗号分隔)

验收标准:
  ✓ 创建后默认状态为"待开始"
  ✓ 截止日期可选，但推荐填写
```

### 3.2 任务状态管理
```
状态流转:
  待开始 → 进行中 → 已完成
     ↓
  已取消

用户可在任何时间转移状态

验收标准:
  ✓ 标记完成时记录完成时间
  ✓ 计算实际耗时
```

### 3.3 任务板视图
```
需求: 用户可以以看板形式查看任务
布局:
  待开始 | 进行中 | 已完成
   卡片   卡片    卡片
   卡片   卡片    卡片

操作:
  - 拖拽卡片改变状态
  - 点击卡片查看详情
  - 快速编辑优先级

验收标准:
  ✓ 支持 Kanban 拖拽
  ✓ 实时同步状态
```

### 3.4 任务过滤和搜索
```
过滤维度:
  - 状态（单/多选）
  - 优先级（单/多选）
  - 截止日期（日期范围）
  - 关联目标
  - 标签（多选）

搜索:
  - 全文搜索（标题 + 描述）

验收标准:
  ✓ 过滤结果实时刷新
  ✓ 支持保存常用过滤条件
```

### 3.5 任务分析
```
需求: 用户可以查看任务相关的统计数据
指标:
  - 本周完成任务数
  - 平均任务耗时
  - 优先级分布
  - 超期任务数
  - 完成率趋势

验收标准:
  ✓ 数据每日更新
  ✓ 支持日/周/月视图
```

## 4. 成就系统

### 4.1 徽章系统
```
需求: 用户通过完成目标和任务解锁徽章

预定义徽章示例:
  🎯 目标大师: 完成 10 个目标
  ✅ 任务完成者: 完成 100 个任务
  🔥 连胜者: 连续 7 天完成任务
  💪 坚持者: 连续 30 天打卡
  ⚡ 闪电: 1 天内完成 5 个任务

验收标准:
  ✓ 自动检测并解锁
  ✓ 解锁时触发邮件通知
  ✓ 支持自定义徽章条件（高级功能）
```

### 4.2 等级系统
```
需求: 用户基于总体表现获得等级

等级定义:
  Lv.1-10: 初心者 (0-1000 积分)
  Lv.11-20: 精英 (1001-5000 积分)
  Lv.21-30: 大师 (5001+ 积分)

积分来源:
  - 完成任务: +10 分
  - 完成目标: +100 分
  - 解锁徽章: +50 分
  - 连续打卡: +5 分/天

验收标准:
  ✓ 等级升级有视觉反馈
  ✓ 等级历史可查看
```

### 4.3 成就页面
```
需求: 用户可以查看自己的所有成就

展示内容:
  - 已解锁徽章（时间线）
  - 当前等级和进度条
  - 下个徽章进度
  - 排行榜排名
  - 成就统计（总完成任务数、目标数等）

验收标准:
  ✓ 美观的展示设计
  ✓ 可分享到社交媒体
```

## 5. 邮件提醒系统

### 5.1 提醒规则配置
```
需求: 用户可以自定义邮件提醒方式

提醒类型:
  1. 任务截止提醒
     - 发送时机: 截止前 1 天、当天上午 8 点
     - 内容: 待完成任务列表
     - 频率: 每日/每周
  
  2. 成就通知
     - 发送时机: 即时
     - 内容: 徽章、等级升升信息
  
  3. 周报/月报
     - 发送时机: 每周一 8 点 / 每月 1 日 8 点
     - 内容: 完成度、成长数据、建议

验收标准:
  ✓ 用户可启用/禁用各类提醒
  ✓ 用户可设置提醒时间（早/午/晚）
  ✓ 支持"勿扰时间"设置
```

### 5.2 邮件模板
```
需求: 提醒邮件有专业的格式和内容

模板要素:
  - 个性化问候（用户昵称）
  - 清晰的行动号召 (CTA)
  - 任务/目标信息卡片
  - 性能统计（可选）
  - 反馈链接和取消订阅

验收标准:
  ✓ 响应式设计（适配移动端）
  ✓ 邮件投递率 > 99%
```

### 5.3 邮件发送状态跟踪
```
需求: 系统记录邮件发送状态

记录内容:
  - 发送时间
  - 收件箱打开状态
  - 链接点击情况
  - 失败原因（如有）

验收标准:
  ✓ 失败邮件自动重试（3 次）
  ✓ 管理员可以查看邮件投递报告
```

## 6. 数据管理

### 6.1 数据导出
```
需求: 用户可以导出个人数据

导出格式:
  - CSV: 任务列表、目标列表、成就列表
  - JSON: 完整的结构化数据
  - PDF: 生成漂亮的报告

导出内容:
  - 基本信息
  - 所有目标（含历史）
  - 所有任务（含历史）
  - 所有成就
  - 活动日志

验收标准:
  ✓ 支持自定义导出字段
  ✓ 导出文件加密
```

### 6.2 数据备份
```
需求: 系统定期备份用户数据

备份策略:
  - 日备份: 每晚 2 点
  - 周备份: 每周日晚
  - 月备份: 每月 1 日晚
  - 保留期: 90 天

验收标准:
  ✓ 备份数据加密存储
  ✓ 用户可手动触发备份
  ✓ 支持从备份恢复数据
```

### 6.3 账户删除
```
需求: 用户可以永久删除账户和数据

流程:
  1. 用户确认删除意图（发送验证邮件）
  2. 7 天冷静期（用户可撤回）
  3. 正式删除账户和所有数据
  4. 发送删除确认邮件

验收标准:
  ✓ GDPR 合规
  ✓ 数据彻底删除（无法恢复）
```

## 7. 权限管理

### 7.1 用户角色
```
系统内置角色:
  - Admin: 系统管理员
  - User: 普通用户（默认）
  - Guest: 访客（可选，查看共享内容）

权限矩阵:
  Admin: 所有权限
  User: 管理自己的内容 + 查看共享内容
  Guest: 仅查看公开共享内容
```

### 7.2 资源权限
```
需求: 用户可以控制目标和任务的共享级别

共享模式:
  - 私有: 仅自己可见
  - 链接分享: 有链接的人可查看
  - 公开: 所有用户可查看

操作权限:
  - 所有者: 查看、编辑、删除、共享
  - 受邀者: 查看、评论（可选）
  - 公众: 仅查看（只读）

验收标准:
  ✓ 权限变更实时生效
  ✓ 支持批量修改权限
```

### 8.1 主仪表盘

```
需求: 用户登陆后看到个人概览

展示内容:
  - 今日统计: 完成任务数、剩余任务数
```

```
需求: 用户可以查看详细的成长数据

图表:
  - 完成率趋势（折线图，过去 90 天）
```
